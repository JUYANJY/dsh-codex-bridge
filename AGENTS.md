## Agent skills

### Issue tracker

Issues and specs live as GitHub issues on `JUYANJY/dsh-codex-bridge`, driven with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its role name: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

single-context — one `CONTEXT.md` at the repo root (skill templates alias it to `GLOSSARY.md`; the name here is `CONTEXT.md`), architecture decisions in `docs/adr/`. See `docs/agents/domain.md`.
